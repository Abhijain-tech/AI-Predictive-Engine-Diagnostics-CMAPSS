# AI-Predictive-Engine-Diagnostics-CMAPSS
AI-driven predictive engine diagnostics and Remaining Useful Life (RUL) prediction using the NASA C-MAPSS turbofan engine dataset. The project evaluates Random Forest, Gradient Boosting, and XGBoost across FD001–FD004 using MAE, RMSE, and R², with feature importance and residual analysis for predictive maintenance insights.
